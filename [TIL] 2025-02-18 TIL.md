## Session

### Stateless Protocol
HTTP는 연결 당 하나의 요청만 처리하는 무상태(stateless) 프로토콜이다. 웹 Server(Servlet)는 하나의 요청에 대해 응답 후 바로 연결을 종료하기 때문에 Client를 구별할 수 없다.

이러한 HTTP 프로토콜의 문제점을 해결하기 위한 방법으로 쿠키, 세션, URL 재작성이 있다.

### Cookie
![](https://velog.velcdn.com/images/pyoung/post/c1266e4d-1f6a-4211-8f77-46d58111a800/image.png)

Cookie는 Key와 Value의 쌍으로 이루어져 있는 문자열이며 유효 기간과 도메인으로 구성되어 있다. 따라서 Cookie 문자열을 특정 기간동안 특정 도메인에서 사용할 수 있도록 한다. Cookie는 Client Web Browser에 저장된다.

Web Client가 요청을 보내면 Web Server을 거쳐 WAS로 전달되며, Servlet에서 `doGet()` 또는 `doPost()` 메서드를 호출한다. 이때 Cookie 문자열을 생성(`set-cookie`)하여 `HTTPServletResponse` 객체의 헤더와 함께 응답하며, 이는 Client Web Browser 내에 저장된다. 이후 Client의 요청이 들어오면 식별 후 저장했던 Cookie를 사용함으로써 Client를 구별할 수 있다.

Cookie는 Clinet에 저장하기 때문에 보안에 취약하다. 또한 문자열이기 때문에 사용성이 낮으며, 길이 제한이 있기 때문에 데이터 저장의 한계가 있다.

> Cookie는 `쿠키이름`, `쿠키값`, `만료시간`, `전송할 도메인명`, `전송할 경로`, `보안연결여부`, `HttpOnly여부`로 구성된다.

### Session
![](https://velog.velcdn.com/images/pyoung/post/58a71bcb-6dd3-4459-827c-65218a682f1a/image.png)

Session은 `HTTPSession` 클래스의 인스턴스이다. Cookie와는 다르게 WAS(Web Server)에 저장되며 cookie를 이용한다.

Web Client가 요청을 보내면 Web Server을 거쳐 WAS로 전달되며, Servlet에서 `doGet()` 또는 `doPost()` 메서드를 호출한다. 이때 Cookie 문자열을 생성하면서 `SessionID`도 함께 생성하여 응답하며, `SessionID` 값에 맞는 데이터를 WAS에 저장한다. 해당 `SessionID`는 Client 당 하나의 값만 할당하며 이를 통해 Client를 구별하여 응답을 한다. 따라서 해당 Client가 다시 요청을 보내면 요청 내 Cookie 값의 `SessionID` 값을 식별하여 WAS 내 데이터를 제공한다.

### `controller` 패키지
```java
// controller.LoginServlet.java

import org.example.loginsessionproject.service.LoginService;
import org.example.loginsessionproject.service.LoginServiceOracleImpl;
import org.example.loginsessionproject.vo.MemberVO;

import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.HashMap;
import java.util.Map;

@WebServlet(value = "/login")
public class LoginServlet extends HttpServlet {
    public LoginServlet() {
    }

    @Override
    public void init() throws ServletException {
        super.init();
    }

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        resp.sendRedirect("loginForm.html");
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        req.setCharacterEncoding("utf-8");

        String id = req.getParameter("id");
        String pw = req.getParameter("pw");

        Map<String, String> map = new HashMap<>();
        map.put("id", id);
        map.put("pw", pw);

        LoginService loginService = new LoginServiceOracleImpl();
        MemberVO member = loginService.login(map);

        resp.setContentType("text/html;charset=utf-8");
        PrintWriter out = resp.getWriter();
        out.println("<html>");
        out.println("<head></head>");
        out.println("<body>");
        if (member != null) {
            // WAS에게 Session 저장 공간 요청
            HttpSession session = req.getSession();
            // HttpSession session = req.getSession(false);
            // 기존 할당된 Session 객체가 이미 존재한다면 사용하고 그렇지 않다면 null을 반환한다.

            session.setAttribute("member", member);  // 값 저장한다.
            // getAttribute() : 값을 꺼내온다.
            // invalidate()   : 세션을 무효화한다.

            out.println("<h1>" + member.getName() + "님 환영합니다.</h1>");
            out.println("<button type=\"button\" onclick=\"location.href='bookSearch'\">" + "도서 검색" + "</button>");
        } else {
            out.println("<h1>실패했어요.</h1>");
            out.println("<button type=\"button\" onclick=\"location.href='login'\">" + "돌아가기" + "</button>");
            out.println("</body>");
            out.println("</html>");
            out.flush();
            out.close();
        }
    }

    @Override
    public void destroy() {
    }
}
```

### `dao` 패키지
```java
// dao.LoginDAO.java

import org.apache.ibatis.session.SqlSession;
import org.apache.ibatis.session.SqlSessionFactory;
import org.example.loginsessionproject.vo.MemberVO;

import java.util.Map;

public class LoginDAO {
    private SqlSessionFactory sqlSessionFactory;

    public LoginDAO(SqlSessionFactory sqlSessionFactory) {
        this.sqlSessionFactory = sqlSessionFactory;
    }

    public MemberVO login(Map<String, String> map) {
        MemberVO member = new MemberVO();

        SqlSession sqlSession = sqlSessionFactory.openSession();
        try {
            member = sqlSession.selectOne("servlet.member.login", map);
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            sqlSession.close();
        }
        return member;
    }
}
```

## HTML 파일 렌더링

### `getWriter()` 메서드
기존에는 `getWriter()` 메서드를 활용하여 `println()`을 통해 HTML 태그를 출력했다.

하지만 Controller에서는 View의 역할을 하지 않기 때문에 이를 분리하고자 한다.

### 정적 리소스
정적 리소스의 경우 매번 HTML 태그를 출력하지말고, `sendRedirect()` 메서드를 통해 HTML 파일을 미리 만들어서 재활용성을 높일 수 있다.
별도의 `loginError.html` 파일을 만든 후 `doPost()` 메서드를 다음과 같이 수정한다.
```java
@Override
protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
	req.setCharacterEncoding("utf-8");

	String id = req.getParameter("id");
    String pw = req.getParameter("pw");

	Map<String, String> map = new HashMap<>();
    map.put("id", id);
    map.put("pw", pw);

	LoginService loginService = new LoginServiceOracleImpl();
	MemberVO member = loginService.login(map);

	if (member != null) {
    	HttpSession session = req.getSession();
        session.setAttribute("member", member);
	} else {
    	resp.sendRedirect("loginError.html");
	}
}
```

### 동적 리소스

동적 리소스의 경우 View의 역할을 하는 JSP 확장자를 통해 화면의 내용을 변경시킬 수 있는 HTML 파일을 만든다.
즉 Java 코드 안에 HTML 코드를 포함시키는 것이 아니라 HTML 코드 안에 Java 코드를 넣는다. 이를 바탕으로 출력 HTML을 좀 더 쉽게 작성할 수 있다.

scriplet 내에는 일반 Java 코드를 작성할 때는 `<% %>`을 사용하고, 문자열을 단독으로 출력하기 위해서는 expression `<%= %>`을 사용한다.
```java
@Override
protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
	req.setCharacterEncoding("utf-8");

	String id = req.getParameter("id");
    String pw = req.getParameter("pw");

	Map<String, String> map = new HashMap<>();
    map.put("id", id);
    map.put("pw", pw);
    
    LoginService loginService = new LoginServiceOracleImpl();
    MemberVO member = loginService.login(map);
	
	if (member != null) {
    	HttpSession session = req.getSession();
        session.setAttribute("member", member);
        
        // JSP를 이용한 View 처리
        RequestDispatcher requestDispatcher = req.getRequestDispatcher("welcome.jsp");
        // request에 데이터 저장
        req.setAttribute("member", member);
        // requestDispatcher 진행
		requestDispatcher.forward(req, resp);
	} else {
    	resp.sendRedirect("loginError.html");
	}
}
```
```jsp
<%--welcome.jsp--%>

<%@ page import="org.example.loginsessionproject.vo.MemberVO" %>
<%@ page contentType="text/html; charset=UTF-8" %>
<html>
<head></head>
<%--scriplet 내에는 일반 Java 코드가 올 수 있다.--%>
<%
    // request 객체에 저장한 member 객체를 가져온다.
    MemberVO member = (MemberVO) request.getAttribute("member");
%>
<%--문자열을 단독으로 출력하기 위해서는 expression을 사용한다.--%>
<body>
    <h1>로그인에 성공했어요.</h1>
    <h1><%= member.getName() %>님 환영합니다.</h1>
</body>
</html>
```

> JSP 파일 역시 `webapp` 파일에서 관리한다.
