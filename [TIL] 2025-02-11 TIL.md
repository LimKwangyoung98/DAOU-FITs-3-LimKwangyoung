## JavaFX

### JavaFX 개념
JavaFX는 표준 GUI 라이브러리였던 Swing을 대체하기 위해 만들어진 GUI 라이브러리이다. <a href="https://gluonhq.com/products/javafx/">JavaFX</a> 페이지에서 설치할 수 있다.

IntelliJ에서 JavaFX를 사용하기 위한 설정을 진행해야한다. 우선 `[IDE 및 프로젝트 설정]` - `[프로젝트 구조]` - `[라이브러리]`로 이동한다. 이후 다운로드한 JavaFX 파일의 `lib` 파일을 라이브러리로 등록한다.
![](https://velog.velcdn.com/images/pyoung/post/0c3f93c0-e413-437b-9feb-ad76ed3d2030/image.png)

또한 VM arguments를 다음과 같이 지정해야 한다. `[마우스 우클릭]` - `[그 외 실행/디버그]` - `[실행 구성 설정]`으로 이동하여 VM 옵션을 추가한 뒤 해당 경로를 지정한다.

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class Main extends Application {
    @Override
    public void start(Stage stage) throws Exception {
        // 화면 구성과 이벤트 처리에 대한 코드

        // 버튼 생성 및 텍스트를 설정한다.
        Button btn = new Button();
        btn.setText("Click");

        // 버튼을 등록하기 위한 Layout Manager를 생성한다.
        StackPane root = new StackPane();
        root.getChildren().add(btn);

        // Layout Manager를 등록하기 위한 Scene을 생성한다.
        Scene scene = new Scene(root, 300, 200);  // width와 height

        stage.setScene(scene);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

이벤트 처리의 구성요소는 다음과 같다.
- Event Source : Event 발생 객체
- Event 객체(자동생성) : Event 세부 정보를 담음
- Event 처리객체(Handler) : 해당 객체의 메서드가 처리

이처럼 객체는 Handler를 통해 이벤트를 전달하며 이를 Delegation Model이라고 한다.

```java
import javafx.application.Application;
import javafx.event.Event;
import javafx.event.EventHandler;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class Main extends Application {
    @Override
    public void start(Stage stage) throws Exception {
        // 화면 구성과 이벤트 처리에 대한 코드

        // 버튼 생성 및 텍스트를 설정한다.
        Button btn = new Button();
        btn.setText("Click");

        // Button이 Event Source에 해당한다.
        // 버튼을 클릭하는 Action Event을 처리하기 위한 Event Handler를 설정한다.
        // EventHandler는 인터페이스이기 때문에 인스턴스를 생성할 수 없다. 따라서 메서드 Overriding을 활용한다.
        EventHandler ev = new EventHandler() {
            public void handle(Event event) {
                // event 처리를 할 때 자동으로 호출한다.
                System.out.println("버튼이 클릭되었습니다.");
            }
        };

        btn.setOnAction(ev);

        // 버튼을 등록하기 위한 Layout Manager를 생성한다.
        StackPane root = new StackPane();
        root.getChildren().add(btn);

        // Layout Manager를 등록하기 위한 Scene을 생성한다.
        Scene scene = new Scene(root, 300, 200);  // width와 height

        stage.setScene(scene);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

> ### `EventHandler`
`EventHandler`는 인터페이스로 구조는 다음과 같다.
```java
package javafx.event;
>
@java.lang.FunctionalInterface
public interface EventHandler <T extends javafx.event.Event> extends java.util.EventListener {
    void handle(T t);
}
```
인터페이스는 인스턴스를 생성할 수 없기 때문에 익명 클래스를 통해 `EventHandler` 인터페이스를 구현한다. 메서드 `handle()`을 오버라이딩한다.
```java
EventHandler ev = new EventHandler() {
	public void handle(Event event) {
    	// Handler 로직
	}
};
```

`EventHandler`를 다음과 같이 작성하기도 한다.
```java
btn.setOnAction(new EventHandler() {
    public void handle(Event event) {
        System.out.println("버튼이 클릭되었습니다.");
    }
});
```

해당 코드에서 인터페이스명 `EventHandler`와 메서드명 `handle`은 고정되어 있기 때문에 다음과 같이 간편하게 작성할 수 있다.
```java
btn.setOnAction((event) -> {
    System.out.println("버튼이 클릭되었습니다.");
    }
);
```

최종 코드는 다음과 같다.
```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class Main extends Application {
    @Override

        Button btn = new Button();
        btn.setText("Click");

        btn.setOnAction((event) -> {
                System.out.println("버튼이 클릭되었습니다.");
            }
        );

        StackPane root = new StackPane();
        root.getChildren().add(btn);

        Scene scene = new Scene(root, 300, 200);

        stage.setScene(scene);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

```java
// Main.java

import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Button;
import javafx.scene.layout.BorderPane;
import javafx.stage.Stage;

public class Main extends Application {
    @Override
    public void start(Stage stage) throws Exception {
        // BorderPane(BorderLayout)
        // 화면을 동서남북과 중앙, 5개의 영역으로 분할한다.
        BorderPane root = new BorderPane();
        root.setPrefSize(300, 300);

        Button btn =  new Button("새 창을 띄웁니다.");
        btn.setPrefSize(300, 50);

        btn.setOnAction(e -> {
            Stage myStage = new MyStage();
            myStage.show();
        });

        root.setBottom(btn);

        stage.setScene(scene);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
```

다음은 버튼을 눌렀을 때의 이벤트를 설정하고자 한다. 우선 버튼을 클릭했을 때의 이벤트를 처리하기 위한 파일을 작성한다.
```java

import java.util.ResourceBundle;

public class MyStageController implements Initializable {
    @Override
    public void initialize(URL url, ResourceBundle resourceBundle) {
        System.out.println("Initialize 메소드가 호출되었습니다.");

```
해당 클래스를 Controller의 역할로 사용하기 위해 인터페이스로 구현한다.

`FXML` 파일을 수정한다. 해당 파일을 Controller로 사용하기 위해 `fx:controller` 속성을 추가한다. 또한 버튼에 대한 이벤트를 위해 `id` 속성을 추가한다.
```html
<FlowPane fx:controller="javafxsimple.MyStageController" maxHeight="-Infinity" maxWidth="-Infinity" minHeight="-Infinity" minWidth="-Infinity" prefHeight="400.0" prefWidth="600.0" xmlns="http://javafx.com/javafx/23.0.1" xmlns:fx="http://javafx.com/fxml/1">
   <children>
      <Button fx:id="firstBtn" mnemonicParsing="false" text="첫번째 Button" textFill="#c41212">
         ...
      </Button>
      <Button fx:id="secondBtn" mnemonicParsing="false" text="두번째 Button">
         ...
      </Button>
   </children>
</FlowPane>
```

버튼에 대한 이벤트를 추가한 `MyStageController` 파일은 다음과 같다.
```java
// MyStageController.java

import javafx.fxml.FXML;
import javafx.fxml.Initializable;
import javafx.scene.control.Button;

import java.net.URL;
import java.util.ResourceBundle;

// 해당 클래스가 Controller가 되려면 특정 인터페이스로 구현해야 한다.
public class MyStageController implements Initializable {
    // Button 컴포넌트의 id
    @FXML private Button firstBtn;
    @FXML private Button secondBtn;

    @Override
    public void initialize(URL url, ResourceBundle resourceBundle) {
        System.out.println("Initialize 메소드가 호출되었습니다.");

        // Event Handling 코드
        firstBtn.setOnAction(e -> {
            System.out.println("첫번째 버튼 클릭");
        });
        secondBtn.setOnAction(e -> {
            System.out.println("두번째 버튼 클릭");
        });
    }
}
```

## VO

### DO와 VO, Entity, DTO
DO(Domain Object)는 도메인에서 사용하는 데이터를 객체화 시킨 것을 의미한다.

VO(Value Object)란 도메인에서 한 개 또는 그 이상의 속성들을 묶어서 특정 값을 나타내는 객체를 의미한다. 테이블의 한 행 데이터를 저장하기 위한 객체를 의미하기도 한다.

Entity는 VO와 비슷한 개념이지만 Primary Key를 포함한다.

DTO(Data Transfer Object)는 VO와 동일한 개념이다. 하지만 의미론적으로 데이터의 전달을 주 목적으로 한다는 점에서 차이가 있다.

### VO 예제
```java
// Main.java

import votest.vo.Book;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.util.ArrayList;
import java.util.List;

public class Main {
    // JDBC를 이용한 데이터 처리
    // 처리된 결과를 VO로 만들어서 출력 객체에게 전달한다.
    public static void main(String[] args) throws Exception {
        Class.forName("oracle.jdbc.driver.OracleDriver");

        String url = "jdbc:oracle:thin:@localhost:1521:xe";
        String id = "C##DEV";
        String pw = "1234";
        Connection con = DriverManager.getConnection(url, id, pw);

        String sql = "SELECT bisbn, btitle, bprice, bauthor ";
        sql += "FROM book ";
        sql += "WHERE btitle LIKE ?";

        PreparedStatement pstmt = con.prepareStatement(sql);
        pstmt.setString(1, "%여행%");

        List<Book> books =  new ArrayList<Book>();
        ResultSet rs = pstmt.executeQuery();
        while (rs.next()) {
            // 출력을 하지않고 자료구조를 만들어서 출력하는 인스턴스에게 전달한다.
            Book newBook = new Book(
                    rs.getString("bisbn"),
                    rs.getString("btitle"),
                    rs.getInt("bprice"),
                    rs.getString("bauthor")
            );
            books.add(newBook);
        }
        PrintResult.printData(books);
    }
}
```

import booksearch1.vo.Book;
import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.fxml.FXML;
import javafx.fxml.Initializable;
import javafx.scene.control.Button;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;
import javafx.scene.control.TextField;
import javafx.scene.control.cell.PropertyValueFactory;

import java.net.URL;
import java.util.ResourceBundle;

public class JavaFXSimpleTableViewController implements Initializable {
    @FXML private TableView<Book> tableView;
    @FXML private TextField textField;
    @FXML private Button searchBtn;
    @FXML private TableColumn<Book, String> isbnCol;
    @FXML private TableColumn<Book, String> titleCol;
    @FXML private TableColumn<Book, Integer> priceCol;
    @FXML private TableColumn<Book, String> authorCol;

    @Override
    public void initialize(URL url, ResourceBundle resourceBundle) {
        isbnCol.setCellValueFactory(new PropertyValueFactory<>("bisbn"));
        titleCol.setCellValueFactory(new PropertyValueFactory<>("btitle"));
        priceCol.setCellValueFactory(new PropertyValueFactory<>("bprice"));
        authorCol.setCellValueFactory(new PropertyValueFactory<>("bauthor"));

        searchBtn.setOnAction(e -> {
            ObservableList<Book> books = FXCollections.observableArrayList();
            
            books.add(new Book("123", "Java 30일 완성", 2000, "홍길동"));
            books.add(new Book("456", "Java 여기까지인가", 7000, "신사임당"));

            tableView.setItems(books);
        });
    }
}

    public void initialize(URL url, ResourceBundle resourceBundle) {

        // tableView 편집 가능
        tableView.setEditable(true);
        titleCol.setCellFactory(TextFieldTableCell.forTableColumn());
        priceCol.setCellFactory(TextFieldTableCell.forTableColumn(new IntegerStringConverter()));
        authorCol.setCellFactory(TextFieldTableCell.forTableColumn());

        // 초기 화면

        searchBtn.setOnAction(e -> searchBooks(textField.getText()));

        // 삭제

        // 수정
        titleCol.setOnEditCommit(e -> updateBook(e.getRowValue().getBisbn(), "btitle", e.getNewValue()));

    public void searchBooks(String keyword) {
        String sql = "SELECT bisbn, btitle, bprice, bauthor ";
        sql += "FROM book ";
        sql += "WHERE btitle LIKE ?";

        ObservableList<Book> books = FXCollections.observableArrayList();
        try {
            // DB에서 데이터 검색
            pstmt = con.prepareStatement(sql);
            pstmt.setString(1, "%" + keyword + "%");

            rs = pstmt.executeQuery();
            while (rs.next()) {
                Book searchBook = new Book(
                        rs.getString("bisbn"),
                        rs.getString("btitle"),
                        rs.getInt("bprice"),
                        rs.getString("bauthor")
                );
                books.add(searchBook);
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
        tableView.setItems(books);
    }

    public void deleteBook() {
        Book selectedBook = tableView.getSelectionModel().getSelectedItem();
        if (selectedBook != null) {
            String sql = "DELETE FROM book ";
            sql += "WHERE bisbn = ?";
            try {
                // DB에서 데이터 삭제
                pstmt = con.prepareStatement(sql);
                pstmt.setString(1, selectedBook.getBisbn());
                pstmt.executeUpdate();

                // tableView에서 데이터 삭제
                tableView.getItems().remove(selectedBook);
            } catch (Exception e) {
                e.printStackTrace();
            }
        }
    }

    public void updateBook(String bisbn, String column, String newValue) {

        sql += "SET " + column + " = ? ";
        sql += "WHERE bisbn = ?";
        try {
            // DB에서 데이터 수정
            pstmt = con.prepareStatement(sql);
            if (column.equals("bprice")) {
                pstmt.setInt(1, Integer.parseInt(newValue));
            } else {
                pstmt.setString(1, newValue);
            }
            pstmt.setString(2, bisbn);
            pstmt.executeUpdate();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

## MVC Pattern

### Layered Architecture
Layered Architecture는 소프트웨어 개발에 가장 기본이 되는 아키텍처로 일반적으로 4계층을 많이 사용한다.
![](https://velog.velcdn.com/images/pyoung/post/e833606e-79ce-4249-8f73-b9294c6a41e6/image.png)

- Presentation Layer
  - 사용자가 데이터를 전달하기 위해 화면에 정보를 표시하는 Layer.
  - 입출력 처리.
  - View와 Controller.
- Business Layer
  - 비즈니스 로직을 수행하는 Layer.
  - 로직 처리.
- Persistence Layer
  - 데이터 출처를 다루는 Layer.
  - DB 접근.
- Database Layer
  - 데이터베이스가 위치한 Layer.
  - Oracle, MySQL 등.
 
해당 구조에서 특정 Layer는 바로 하위 레이어에만 연결된다.

### MVC Pattern
Model-View-Controller의 약자이다.

어플리케이션을 세 개의 영역으로 분할하고 각 구성 요소에게 역할을 부여한다. Layered Architecture와 유사하다.

![](https://velog.velcdn.com/images/pyoung/post/e51d0e14-65be-4cc4-af48-05107d48c475/image.png)

### Model
Model은 Domain Model과 Service Model로 구분된다.

**Domain Model**
로직에서 처리하는 데이터를 의미한다. 도메인 객체, VO, DTO에 해당하며 비즈니스 로직을 처리하지 않는다.
여기서 데이터를 처리하는 객체를 DAO(Data Access Object)라고도 하며, Model과 DB는 DAO를 통해 통신한다.

> 도메인 모델 역할을 하는 클래스는 도메인 객체라고 한다.

**Service Model**
도메인 객체를 이용하여 비즈니스 로직을 처리한다. 데이터에 대한 접근을 제공하는 역할을 수행한다.

### View
유저 인터페이스(User Interface)를 의미한다. MVC 패턴에는 여러 개의 View가 존재할 수 있으며 Model에게 질의하여 데이터를 전달받는다.

### Controller
Model과 View 사이를 이어주는 다리 역할을 수행한다. 사용자가 어플리케이션을 조작하여 발생하는 이벤트들을 처리하는 역할을 수행한다.
