## JDBC

### JDBC 개요
JDBC(Java DataBase Connectivity)는 Java를 이용하여 데이터베이스에 있는 값을 활용하기 위한 API이다. 여기서 JDBC Driver는 Java 응용 프로그램이 데이터베이스와 상호작용할 수 있도록 하는 소프트웨어 구성 요소이다.

DBMS는 종류에 따라 굉장히 많은 클래스와 인터페이스를 제공하는데, 일반적으로 DBMS를 변경하면 이에 해당하는 코드를 모두 변경해야 한다. 하지만 JDBC Driver가 공통된 클래스와 인터페이스를 제공하여 일관된 사용을 가능하게 한다.

## JDBC 활용 과정

JDBC 활용 과정은 총 6단계이다.

### JDBC 드라이버 등록
최초 1회만 수행한다.
```java
import java.sql.*;

public class FirstConnect {
    public static void main(String[] args) {
        Connection con = null;
        try {
            // 1단계
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("드라이버 로딩 성공");
        } catch (ClassNotFoundException e1) {
            System.out.println("Driver를 찾을 수 없어요.");
        }
    }
}
```

### 데이터베이스 연결
DBMS의 설치된 위치와 아이디, 비밀번호를 이용하여 연결을 시도한다. 연결이 성공하면 결과로 객체가 생성되며 객체의 클래스는 `java.sql.Connection`이다.

연결을 위한 정보는 다음과 같다.
- `JDBC_URL` : 어떤 데이터베이스에 접속하는지에 대한 정보(문자열)
- `ID` : 아이디
- `PW` : 비밀번호

```java
import java.sql.*;

public class FirstConnect {
    public static void main(String[] args) {
        Connection con = null;
        try {
            // 1단계
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("드라이버 로딩 성공");

            // 2단계
            String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
            String ID = "C##DEV";
            String PW = "1234";
            con = DriverManager.getConnection(JDBC_URL, ID, PW);
            System.out.println("데이터베이스 연결 성공");
        } catch (ClassNotFoundException e1) {
            System.out.println("Driver를 찾을 수 없어요.");
        } catch (SQLException e2) {
            System.out.println("연결에 문제가 있어요.");
        }
    }
}
```

### SQL 작성
`Connection` 객체로부터 `Statement` 객체를 생성한다. `Statement` 객체는 총 세 가지가 있다.
- 일반 `Statement`
  - 단순하지만 기능 상으로 부족할 수 있음.
- `PreparedStatement`
  - 주로 사용.
  - 코드 작성하기 편함.
  - 효율이 좋음.
  - SQL Injection을 방지.
- `CallableStatement`
  - Stored Procedure을 호출하기 위해 사용.
  
```java
import java.sql.*;

public class FirstConnect {
    public static void main(String[] args) {
        Connection con = null;
        PreparedStatement pstmt = null;
        try {
            // 1단계
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("드라이버 로딩 성공");

            // 2단계
            String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
            String ID = "C##DEV";
            String PW = "1234";
            con = DriverManager.getConnection(JDBC_URL, ID, PW);
            System.out.println("데이터베이스 연결 성공");

            // 3단계
            String sql = "SELECT btitle FROM book WHERE bisbn='89-7914-063-0'";
            pstmt = con.prepareStatement(sql);
        } catch (ClassNotFoundException e1) {
            System.out.println("Driver를 찾을 수 없어요.");
        } catch (SQLException e2) {
            System.out.println("연결에 문제가 있어요.");
        }
    }
}
```

### Query 실행
`Statement`에 선언된 `execute()` 메소드를 활용하여 SQL 구문을 실행한다.
- `executeUpdate()` : SQL 구문이 `INSERT`, `UPDATE`, `DELETE` 계열일 때 사용
- `executeQuery()`  : SQL 구문이 `SELECT` 일 때 사용

```java
import java.sql.*;

public class FirstConnect {
    public static void main(String[] args) {
        Connection con = null;
        PreparedStatement pstmt = null;
        ResultSet rs = null;
        try {
            // 1단계
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("드라이버 로딩 성공");

            // 2단계
            String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
            String ID = "C##DEV";
            String PW = "1234";
            con = DriverManager.getConnection(JDBC_URL, ID, PW);
            System.out.println("데이터베이스 연결 성공");

            // 3단계
            String sql = "SELECT btitle FROM book WHERE bisbn='89-7914-063-0'";
            pstmt = con.prepareStatement(sql);

            // 4단계
            rs = pstmt.executeQuery();
        } catch (ClassNotFoundException e1) {
            System.out.println("Driver를 찾을 수 없어요.");
        } catch (SQLException e2) {
            System.out.println("연결에 문제가 있어요.");
        }
    }
}
```

### 결과처리
실행 후 결과를 `ResultSet` 혹은 `int`형 변수로 받아서 처리한다.
- `executeUpdate()`
  - 반환값은 SQL에 의해서 영향을 받는 행의 수(`int`).
- `executeQuery()`
  - `ResultSet`이 데이터베이스의 첫 번째 행을 가리킴.
  - `rs.next()`를 통해 다음 행으로 갈 수 있는지에 대한 여부를 판단하고 다음 행으로 넘어감.
  - `rs.getInt()` 또는 `rs.getString()`을 통해 지정된 컬럼의 값을 가져옴.
  - 해당 과정은 `rs.next()` 값이 `false`일 때까지 반복.

```java
import java.sql.*;

public class FirstConnect {
    public static void main(String[] args) {
        Connection con = null;
        PreparedStatement pstmt = null;
        ResultSet rs = null;
        try {
            // 1단계
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("드라이버 로딩 성공");

            // 2단계
            String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
            String ID = "C##DEV";
            String PW = "1234";
            con = DriverManager.getConnection(JDBC_URL, ID, PW);
            System.out.println("데이터베이스 연결 성공");

            // 3단계
            String sql = "SELECT btitle FROM book WHERE bisbn='89-7914-063-0'";
            pstmt = con.prepareStatement(sql);

            // 4단계
            rs = pstmt.executeQuery();

            // 5단계
            // 기본적으로 rs가 데이터를 가키리고 있지 않다.
            if (rs.next()) {
                System.out.println(rs.getString("btitle"));
            } else {
                System.out.println("검색 결과가 없습니다.");
            }
        } catch (ClassNotFoundException e1) {
            System.out.println("Driver를 찾을 수 없어요.");
        } catch (SQLException e2) {
            System.out.println("연결에 문제가 있어요.");
        }
    }
}
```

### JDBC 활용 예제
```java
// 책 제목에 대한 키워드를 입력 받아서
// 책 제목에 해당 키워드를 포함하고 있는 책을 검색한 다음
// 해당 책에 대한 책 ISBN, 제목, 저자, 가격 정보를 출력하시오.

import java.sql.*;
import java.util.Scanner;

public class SecondConnect {
    public static void main(String[] args) {
        Connection con = null;
        PreparedStatement pstmt = null;
        ResultSet rs = null;
        try {
            // 1. (JDBC) Driver Loading
            Class.forName("oracle.jdbc.driver.OracleDriver");

            // 2. 데이터베이스 연결(Connection 생성)
            String jdbcURL = "jdbc:oracle:thin:@localhost:1521:xe";
            String id = "C##DEV";
            String pw = "1234";
            con = DriverManager.getConnection(jdbcURL, id, pw);

            Scanner s = new Scanner(System.in);
            System.out.print("검색어를 입력하세요: ");
            String keyword = s.nextLine();

            // 3. SQL 작성
            String sql = "SELECT bisbn, btitle, bauthor, bprice ";
            sql += "FROM book ";
            // PreparedStatement에서 사용 가능한 IN Parameter를 활용한다.
            // SQL Injection을 막을 수 있다.
            sql += "WHERE btitle LIKE ?";
            pstmt = con.prepareStatement(sql);
            pstmt.setString(1, "%" + keyword + "%");

            // 4. Query 실행
            rs = pstmt.executeQuery();

            // 5. 결과처리
            while (rs.next()) {
                System.out.println(rs.getString("bisbn")
                        + " " + rs.getString("btitle")
                        + " " + rs.getString("bauthor")
                        + " " + rs.getString("bprice"));
            }

            // 6. 리소스 해제
            rs.close();
            pstmt.close();
            con.close();
        } catch (Exception e) {
            System.out.println("에러 발생: " + e.getMessage());
        }
    }
}
```

> ### In Parameter
In Parameter의 사용 목적으로는 다음과 같다.
- SQL Injection 방지
- 쿼리 재사용
- 코드 가독성 및 유지보수성
>
`?`을 사용한 SQL 구문을 작성하고 `setString()`, `setInt()` 등의 메서드를 통해 바인딩한다. 파라미터 정보는 다음과 같다.
- `index` : 순서대로 `?`의 순서를 가지며 1부터 시작
- `value` : 바인딩 값


## 트랜잭션

트랜잭션(Transaction)이란 작업(일)의 최소 단위이다. SQL 구문 5개를 트랜잭션으로 설정할 수 있다.

트랜잭션을 설정하는 이유는 ACID를 보장하기 위해서이다. Oracle에서는 자동으로 지원한다.
- Atomicity(원자성) : All or Nothing
- Consistency(일관성)
- Isolation(독립성)
- Durability(지속성)

### JDBC에서의 트랜잭션
```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;

public class TransactionTest {
    public static void main(String[] args) {
        Connection con = null;
        PreparedStatement pstmt;
        try {
            // 1. Driver Loading
            Class.forName("oracle.jdbc.driver.OracleDriver");

            // 2. Connection 연결
            String url = "jdbc:oracle:thin:@localhost:1521:xe";
            String id = "C##DEV";
            String pw = "1234";
            con = DriverManager.getConnection(url, id, pw);
            // 기본적으로 autoCommit Mode로 Connection이 생성된다.
            // 하나의 SQL 구문은 곧바로 Commit된다.
            // 이를 해제하여 Transaction으로 처리하려면 다음 명령어를 사용한다.
            con.setAutoCommit(false);  // Transaction 시작
            // 명시적으로 con.commit() 또는 con.rollback()이 호출되면 Transaction이 종료된다.
            // 만약 해당 구문이 나오지 않고 Connection이 정상 종료되면 con.commit()으로 간주한다.

            // 3. SQL 구문 작성
            String sql = "INSERT INTO memberTbl VALUES (?, ?)";
            pstmt = con.prepareStatement(sql);
            pstmt.setString(1, "2");
            pstmt.setString(2, "신사임당");

            // 4. SQL 구문 실행
            int result = pstmt.executeUpdate();  // 반환값은 영향받은 행의 수

            // 5. 결과 처리
            if (result == 1) {
                System.out.println("처리되었습니다.");
            }

            con.commit();       // Transaction 적용 및 종료
            // con.rollback();  // Transaction 무효화

            // 6. 리소스 해제
            pstmt.close();
            con.close();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```
